# StockFlow

Sistema web de gestión de inventario y ventas para pequeñas y medianas empresas.

Características:
- Gestión de productos
- Control de stock
- Registro de ventas
- Roles y permisos
- Reportes

Tecnologías:
- PHP
- MySQL
- JavaScript
- Bootstrap
- Apache (XAMPP)
